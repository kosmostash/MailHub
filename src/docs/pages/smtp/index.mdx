# Submitting email over SMTP

Anything that already sends mail can submit to MailHub by pointing its outgoing SMTP
settings at the MailHub listener. Messages are **stored, never relayed**: they enter the
same review and send pipeline as HTTP submissions.

| Setting | Value |
| --- | --- |
| Host | your MailHub host |
| Port | `2525` (`MAILHUB_SMTP_PORT`) |
| Encryption | none (private network; STARTTLS is disabled) |
| Authentication | PLAIN or LOGIN |
| Username | anything, or the collection id |
| Password | the collection id |

The `250` reply means the message is durably stored. Its id and state are in the reply
text, e.g. `2.0.0 Stored as cb14a59e-… (pending)`.

## Rejections

| Reply | Meaning |
| --- | --- |
| `535 5.7.8 Unknown collection` | the credential is not a collection id |
| `535 5.7.1 Collection suspended (…)` | the operator or admin is disabled |
| `550 5.6.0 …` | the message could not be stored as an email (e.g. no recipients) |
| `552 5.3.4` | larger than `MAILHUB_SMTP_MAX_MESSAGE_BYTES` (25 MB by default) |
| `451 4.3.0` | temporary storage failure; retry |

Recipients in the SMTP envelope that do not appear in `To` or `Cc` are stored as `Bcc`.
